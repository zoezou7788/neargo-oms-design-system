# NearGo OMS 设计规范（全站通用）

**Design System v2.2** · 2026-05

本规范为 **NearGo OMS（Order / Operations Management System）全产品**的通用视觉与交互基线，适用于各业务域：**订单与交易、门店与商户、商品与营销、财务与结算、权限与组织、报表与运营总览、配置与工作流** 等。具体模块仅在**数据字段与文案**上差异化，**不得**自造一套颜色、圆角或字号体系。

基于 Radix UI 色阶方法论与 NearGo 品牌识别构建。v2.1 起吸收 **Soft Dashboard** 类参考在**留白、纵向节奏、仪表板栅格**上的排版范式；**v2.2** 将原文中偏单场景的示例**泛化为全站语言**，避免读者误以为规范仅服务某一功能。

**标签：** 全站 OMS · Radix Color Scale · Inter + JetBrains Mono · 1440px 视口 · WCAG AA+ · Soft UI（仪表板）

### 适用范围（必读）

| 范畴 | 内容 |
|------|------|
| **必须遵守** | 色阶与语义色角色、灰阶用法、字号 token、间距与圆角档位、按钮变体、输入可达性、状态「点 + 文」、阴影上限 |
| **按场景选用** | 仪表板问候与全宽重点卡、双栏底区、侧栏内搜索、KPI 横条、右侧上下文面板、时间线组件 |
| **允许扩展** | 业务专属 **badge / 实体类型色** — 须沿用 **bg-2 + border-3 + text-11** 模式，并在团队设计附录或组件库中**登记 token 名**，禁止随意 hex |

## 01 色彩

### Color System

遵循 Radix UI 12 级语义色阶；每一级都有定义好的角色，而不是随意选号。琥珀色阶（第 9 步锚定为 **#FFA902**）为 NearGo 品牌色板。灰色第 12 步（**#1F1D1C**）为主要操作色。

### 品牌色使用规则

- **1–2：** 页面与卡片背景淡色，用于营销区块
- **6–8：** 品牌相关组件的描边与聚焦环
- **9（#FFA902）：** 实心填充 — 促销徽章、特价、活动高亮
- **11：** 白底上的文字 — 折扣标签、优惠文案（Lc ≥ 60 APCA）
- **任意单屏视觉面积中品牌色 ≤ 10%。** 不得用于主要操作按钮。

## 02 字体

### Typography

拉丁文使用 Inter，代码与 ID 使用 JetBrains Mono，中文使用 Noto Sans SC。每个字号 token 包含字号 + 行高 + 字间距，与 Radix 比例尺一致。

### Font Families

| 角色 | 字体 | 字重范围 | 用途 |
|------|------|----------|------|
| Sans（主） | Inter | 300–800 | 全部 UI 文字、标签、按钮、标题 |
| CJK | Noto Sans SC | 400, 500, 700 | 中文内容，与 Inter 同屏加载 |
| Mono | JetBrains Mono | 400, 500 | **业务主键**（订单号、批次号、配置 ID）、时间戳、IP、代码片段 |

### Type Scale（9 级）

| Token | 规格 | 用途 |
|-------|------|------|
| size-1 | 12 / 1.0 / +0.04em · w-400 | 全大写微标签、表头列名 |
| size-2 | 12 / 1.5 / +0.01em · w-400 | 时间戳、次要元信息、字段提示 |
| size-3 | 13 / 1.5 / 0em · w-400 | 表格单元格、导航项、徽章文字 |
| size-4（默认） | 14 / 1.6 / -0.01em · w-400 | 正文、表单值、描述 |
| size-5 | 14 / 1.5 / -0.01em · w-500 | 表格主列、强调字段值 |
| size-6 | 16 / 1.4 / -0.02em · w-600 | 表单分区标题、卡片标题、对话框标题 |
| size-7 | 20 / 1.3 / -0.03em · w-700 | 页面标题（面包屑）、区块主标题 |
| size-8 | 26 / 1.1 / -0.04em · w-700 | KPI 数值 |
| size-9 | 36 / 1.0 / -0.05em · w-800 | 大号展示统计 |

### 仪表板与欢迎区排版（参考 Soft UI）

参考图共性：**左对齐强纵轴**、**大留白**、**问候语作为页内第一视觉锚点**。在 OMS 中映射如下（仍使用 Inter / Noto Sans SC，不另引第三方品牌字体）。

| 层级 | Token / 规格 | 字色 | 用途 |
|------|----------------|------|------|
| 面包屑 | size-2，w-400 | gray-9 | 路径导航；置于内容区最顶，**不与**页面 H1 争对比 |
| 页内问候 / Hero 标题 | **28px / 1.15 / -0.03em · w-700**（介于 size-7 与 size-8 之间的**仪表板专用**档） | gray-12 | 「Good morning, {name}」类个性化抬头；**每页至多一处** |
| 问候副文案 | size-4，w-400 | gray-11 | 一句说明当前上下文（如今日待办、数据范围） |
| 区块眉（Eyebrow） | size-1，全大写 | gray-8 | 如「TOP PRIORITY TODAY」— 与 [01 色彩](#01-色彩) 中微标签角色一致 |
| 分区标题 | size-6，w-600 | gray-12 | 「Today's Schedule」「Recent Activity」等模块标题 |
| 列表主行 | size-4 或 size-5 | gray-12 / gray-11 | 日程标题、动态标题 |
| 列表元信息 | size-2 | gray-9 | 时间戳、截止提示、次要说明 |

**原则：** 仪表板首页的层级主要靠 **字号梯度 + 留白**，而非增加高饱和色块；彩色仅用于 **小图标、左侧 3–4px 分类条、状态点**（与既有「点 + 文」规则一致）。

## 03 间距与圆角

### Spacing & Radius

9 级间距自 4px 至 64px。6 级圆角按组件类型上下文应用，与 Radix Themes 上下文圆角模型一致。

### Spacing Scale

| Token | 值 | 用途 |
|-------|-----|------|
| space-1 | 4px | 图标间距、微内边距 |
| space-2 | 8px | 徽章内边距、行内间距 |
| space-3 | 12px | 行单元格间距、紧凑列表 |
| space-4 | 16px | 表单字段间距、按钮内边距 |
| space-5 | 24px | 卡片内边距、区块间距 |
| space-6 | 32px | 块级间距、大区块 |
| space-7 | 40px | 内容区内边距 |
| space-8 | 48px | 页面顶部偏移 |
| space-9 | 64px | 区块分隔、主视觉区 |

### 区块垂直节奏（Section Rhythm）

参考图特征：**大区块之间有明显「呼吸」**，避免表格式密集堆叠。在内容区（见 [05](#05-页面布局)）内约定：

| 关系 | 间距 Token | 说明 |
|------|--------------|------|
| 面包屑 → 问候标题 | space-4（16px） | 紧凑衔接 |
| 问候区 → 下方 KPI 横条 | space-6～space-7 | 仪表板首页；**至少 space-6** |
| KPI 横条 → 下方「全宽重点卡」 | space-6 | 单卡独占一行时 |
| 全宽重点卡 → 次级卡片行 | space-7 | 强调层级断裂 |
| 卡片行 → 底区双栏 | space-7～space-8 | 双栏为「主列表 | 侧动态」 |
| 同列多卡片堆叠 | space-5 | 卡片间距；内边距统一 **space-5（24px）** 为软质界面默认 |

**双栏比例（仪表板底区）：** 主列（日程 / 大表）:**侧列（动态 / 辅助）** ≈ **1.5fr : 1fr** 至 **2fr : 1fr**（约 60/40～66/33），侧列 **min-width 280px**，避免动态流过窄。

### Radius Scale

| Token | 值 | 用途 |
|-------|-----|------|
| radius-1 | 3px | 复选框、极小标签内层 |
| radius-2 | 4px | 徽章、状态条、标签 |
| radius-3 | 6px | 按钮、输入、下拉 |
| radius-4 | 8px | **数据卡片、表格容器、KPI 小卡**、下拉、浮层（默认） |
| radius-5 | 12px | **仪表板全宽重点卡、欢迎容器**；对话框、抽屉、模态 |
| radius-6 | full（9999px） | 头像、药丸按钮、开关 |

**Soft UI 与圆角：** 参考图常见 **10–14px** 观感；在 OMS 中**收敛为 token**：仪表板「唯一主角」级表面用 **radius-5**，其余保持 **radius-4**，避免全页统一大圆角导致表格页与首页气质冲突。

## 04 阴影与描边

### Shadow & Border

尽量少用抬升感。多数表面仅用灰阶 1px 描边（6–8 级）。阴影分层递进，常用双层以表达深度。

### Shadow Scale

| Token | 值 / 说明 | 用途 |
|-------|-----------|------|
| shadow-1 | `0 1px 2px rgba(0,0,0,.05)` | 行 hover 轻微抬升 |
| shadow-2 | 双层 · `0 1px 3px` 等 | 卡片、统计块；**仪表板大卡可与 1px gray-6 描边二选一或并用（极轻）** |
| shadow-3 | 双层 · `0 4px 8px` 等 | 右侧固定上下文面板、抽屉内「重」操作区 |
| shadow-4 | 双层 · `0 8px 16px` 等 | 下拉、Popover |
| shadow-5 | `0 16px 32px rgba(0,0,0,.10)` | 底部动作浮层 |
| shadow-6 | `0 24px 48px rgba(0,0,0,.18)` | 模态对话框 |

### Border Usage Rules

| 场景 | 样式 | Gray Step |
|------|------|-----------|
| 卡片 / 面板默认描边 | `1px solid #dddbd8` | step-6 |
| 输入框默认 | `1px solid #cac8c4` | step-7 |
| 输入框 hover | `1px solid #b0adaa` | step-8 |
| 输入框聚焦环 | `border: 1px solid #1F1D1C` + `box-shadow: 0 0 0 2px #eceae7` | step-12 + step-4 |
| 导航激活指示条 | `border-left: 2px solid #FFA902` | Brand step-9 |
| 表格行分隔线 | `1px solid #f2f1ef` | step-3 |

## 05 页面布局

### Page Layout

固定 **1440px** 视口。三区域外壳：顶部品牌条（54px 高）+ 固定左侧边栏（232px）+ 可滚动内容区。内容区内边距 **24px**，版面留白充足。

| 区域 | 尺寸 | 背景 | 说明 |
|------|------|------|------|
| 顶部品牌条 | 100% × 54px，fixed | #ffffff | 产品名、版本、用户操作；底边 1px gray-6 |
| 左侧边栏 | 232px × 100vh，fixed | #ffffff | 导航；右侧 1px gray-6；无阴影 |
| 内容区 | `calc(100vw − 232px)`，滚动 | gray-1 (#fdfdfc) | **默认** 24px padding；最大内容宽 **1100px** 居中 |
| 内容区（仪表板宽松模式） | 同上 | 同上 | padding **28～32px**（space-5～space-6）；max-width **1120～1200px** 可选，仍保持两侧留白，不铺满到边缘 |
| 右侧详情面板 | 320～400px，可选 fixed | #ffffff | **任意模块**的详情、备注、工作流结论、对比信息；左侧 1px gray-6 |
| 内容卡片 | 流式 100% | #ffffff | **默认** radius-4、shadow-2、边框 gray-6；**仪表板全宽重点卡** 见 [03](#03-间距与圆角) radius-5 |

### 内容区纵向结构模板（仪表板 / 运营总览）

自上而下推荐栈（**任意**需要「一屏总览」的模块均可复用：订单看板、商户健康度、库存预警总览等；组件与 [07](#07-kpi-卡片)、[14](#14-活动时间线与审计轨迹) 组合）：

1. **面包屑**（可选）  
2. **问候 + 一句副文案**（首页或「我的工作台」推荐）  
3. **横向 KPI 指标条** — 与 [07](#07-kpi-卡片) 一致；项与项之间用 **space-5～space-6** 分隔，少用竖线分割  
4. **全宽重点卡（单张）** — 全站最高优先级告警、今日 SLA、或跨模块摘要；**radius-5**，内边距 **space-5～space-6**  
5. **次级卡片行** — 2～4 张等宽栅格，`grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))`，gap **space-5**  
6. **底区双栏** — 左：主列表 / 日程 / 图表；右：**最近动态**、快捷入口或次要列表；右栏卡片同 shadow-2  

**顶栏全局搜索（若采用）：** 置于品牌条内、偏左宽字段；高度与 54px rail 对齐；样式遵循 [11](#11-输入与表单) 默认态；可附 **⌘K** 提示（size-2、gray-8），不抢占主标题对比度。

## 06 导航

### Sidebar Navigation

侧栏为 **全站唯一主导航骨架**：产品名与版本、按**域**分组（如运营、商户、商品、系统）、主项与子项、底部用户与环境入口（帮助、退出等）。各模块仅贡献菜单项与路由，**不改变**侧栏宽度与状态样式 token。

**可选增强（参考 Soft 侧栏）：**

- **侧栏顶部主行动（如「新建 / New」）**：使用 **btn-s** 或 **带 gray-7 描边的幽灵主按钮**，**radius-6** 药丸形；与内容区 **btn-p** 区分层级（侧栏为「入口」，页面内为「当前任务主提交」）。  
- **侧栏内搜索**：宽度 `100% − 32px` 水平居中于分组内；高度 **34～36px**，radius-3；占位符 gray-9；快捷键提示同顶栏。  
- **子项层级**：相对父级 **左缩进 8px**（与现有子导航一致）；父级展开用 **gray-11 + chevron**，勿用高饱和指示色。

### 导航状态

| 状态 | 背景 | 文字 | 左边框 |
|------|------|------|--------|
| Default | transparent | gray-11 (#4a4846) | 无 |
| Hover | gray-2 (#f9f9f8) | gray-12 (#1F1D1C) | 无 |
| Active | amber-2 (#fff8d6) | gray-12，字重 500 | 2px amber-9 (#FFA902) |
| 分组标题 | — | gray-8，全大写，size-1 | — |

- **行高：** 主项 32px，子项 30px  
- **内边距：** 7px 16px；子项左侧缩进 8px

## 07 KPI 卡片

### KPI & Stat Cards

- **Dashboard KPI：** shadow-2，radius-4。含图标区、大号数值、主标签、副说明（如「今日 GMV」「待发货单量」「异常门店数」等**任意指标**）。
- **列表页摘要条：** 可使用 amber-2 / blue-2 / purple-2 等淡色底 + 对应 border token，展示**与当前列表相关的**队列或筛选摘要（如「待我处理」「待审核」「待付款」）；**队列 ≠ 危险**：不要用红色表示中性排队（见 [16](#16-设计原则) 反模式）。

### 横向指标条布局（参考图）

- **容器：** 无独立大边框时，用 **透明底 + 项之间 space-5～space-6**；若需与背景区分，使用 **surface + shadow-1 + radius-4**，避免过重 shadow-3。  
- **每项结构：** 小图标（轮廓、**20px** 区域）+ **size-8 / w-700** 数字 + **size-3 / gray-11** 标签；数字与标签垂直间距 **space-1～space-2**。  
- **图标色：** 使用 **语义 pastel** — 仅从已有 **blue-2 / green-2 / amber-2 / purple-2** 等背景阶取图标底，**solid 图标用对应 9 阶的降低透明度版本或 gray-11**，禁止新造未在色阶表内的 hex。

## 08 数据表格

### Data Table

**全站列表页** 共享同一套密度与控件：顶区 **搜索 + 筛选 + 结果计数 + 可选批量操作**；主体为行式数据；底区 **分页或虚拟滚动提示**。

列示例仅作占位，实际列由各域定义：**主键列**（订单号、门店编码等）、**类型/标签**、**标题或名称**、**金额或数量**（若适用）、**状态**、**时间**、**行内操作**。

- **主键、时间** 使用等宽字体、较小字号、灰色提示层级（见 [02](#02-字体)）。  
- **行内操作：** 以 **btn-ghost / 文字链** 打开详情；需肯定/否定语义时再用 **btn-g / btn-d**（如「确认退款」「停用账号」），与 [10](#10-按钮) 一致。

## 09 徽章与状态

### Badges & Status Indicators

每个徽章遵循 Radix 语义模式：**step-2 背景 · step-3 边框 · step-11 文字**。状态使用 **6px 圆点 + 文字**。品牌琥珀仅用于促销语境。

### Badge Tokens（示例 — 可扩展）

下表为 **已登记** 的实体/优先级徽章示例；新业务类型新增 `b-*` 时须满足 **step-2 底 + step-3 边 + step-11 字**（或品牌特例 `b-brand`），并在设计附录中补充一行，保证全站可检索。

| Token | BG | Border | Text | 典型用途（可映射到多模块） |
|-------|-----|--------|------|------------------------------|
| b-kyc | #ecfcfd | #b8ecf5 | #107ea0 | 个人实名 / 身份类实体或任务 |
| b-kyb | blue-2 | blue-3 | blue-11 | 企业资质 / B 端认证类 |
| b-store | purple-2 | purple-3 | purple-11 | 门店、网点、渠道类 |
| b-urgent | red-2 | red-3 | red-11 | 优先级 = 紧急（非「排队中」） |
| b-normal | gray-2 | gray-6 | gray-11 | 优先级 = 普通 |
| b-low | amber-2 | amber-3 | amber-11 | 优先级 = 低（品牌淡色，非实心） |
| b-brand | amber-9 (#FFA902) | 无 | amber-12 | 全站促销、加购服务 — **每屏 ≤ 1** |

### 行内状态（通用模式）

凡表示 **进展、结果、队列位置** 的状态，均采用 **6px 色点 + 文字标签**；文案由各业务定义（如「待初审 / 待发货 / 已关闭」），**色点颜色须对应 [01](#01-色彩) 语义角色**，且同一模块内 **队列类状态勿用 red** 表示中性等待。

## 10 按钮

### Buttons

**主操作使用 gray-12 (#1F1D1C)** — 建立信任的主导色。正向与危险分别使用语义绿、红。**品牌琥珀严格留给促销 CTA。**

### Button Variants

| Variant | 背景 | 文字 | 何时使用 | 限制 |
|---------|------|------|----------|------|
| **btn-p (Primary)** | gray-12 #1F1D1C | #fff | 当前视图最重要的一条操作 | 同一层级仅一个 |
| btn-s (Secondary) | #fff + border gray-7 | gray-12 | 取消、返回、重置，与主按钮并列 | — |
| btn-g (Positive) | green-9 #29a383 | #fff | 明确肯定后果的操作（通过、启用、确认收款等） | 常与 btn-d 成对用于二选一决策 |
| btn-d (Danger) | red-9 #e5484d | #fff | 拒绝、删除、作废、退款等破坏性或可逆性低的操作 | 必须二次确认 |
| btn-ghost | transparent | blue-11 | 详情链接、「查看全部」等轻导航 | 不用于主流程关键步 |
| **btn-brand** | amber-9 #FFA902 | amber-12 | 仅促销 / 优惠相关 CTA | **每屏 ≤ 1，绝不用于工作流主操作** |

## 11 输入与表单

### Inputs & Form Layout

输入框默认 **gray-7** 边框，聚焦时 **gray-12** 边框 + **gray-4** 外发光 — 符合 Radix 聚焦模式。**标签始终可见**，禁止仅用 placeholder 充当标签。

### 输入状态

| 状态 | Border | BG | Focus ring |
|------|--------|-----|--------------|
| Default | `1px solid gray-7 (#cac8c4)` | #ffffff | — |
| Hover | `1px solid gray-8 (#b0adaa)` | #ffffff | — |
| Focus | `1px solid gray-12 (#1F1D1C)` | #ffffff | `0 0 0 2px #eceae7 (gray-4)` |
| Error | `1px solid red-9 (#e5484d)` | #ffffff | `0 0 0 2px red-3 (#ffe0e0)` |
| Read-only | `1px solid gray-6 (#dddbd8)` | gray-2 (#f9f9f8) | — |
| Disabled | `1px solid gray-5` | gray-3 | —，`cursor: not-allowed` |

表单分区：分区标题（size-6）+ 可选描述；字段网格两列排布**常见成对字段**（名称与编码、起止日期、省与市等）。**任意业务表单**均遵守同一标签、错误态与只读态规则。

### Detail View

业务对象只读快照（订单摘要、商户档案、配置只读等）以**两列只读网格**展示。字段标签使用 **size-1 全大写 gray-8**；字段值使用 **size-5 gray-12**。敏感信息（证件号、手机、密钥）采用掩码 + mono 展示。

## 13 上下文面板

### Context Panel（右侧或抽屉内）

**全站复用**的窄栏或抽屉容器，用于「在当前列表/详情旁完成附属任务」，不仅限于审批。常见变体：

- **工作流结论区**：标题 + 当前角色/权限说明 + 互斥选项（通过/拒绝/退回等）+ 备注 + **Submit**（btn-p）/ **Cancel**（btn-s）
- **快速编辑区**：少量字段就地修改 + 保存
- **对比与引用**：展示关联单据摘要、风险摘要而不跳转页

视觉：**shadow-3** 以内；宽度 **320～400px**；与 [05](#05-页面布局) 右栏一致；内部表单规则同 [11](#11-输入与表单)。

## 14 活动时间线与审计轨迹

### Activity & Audit Timeline

用于 **订单日志、审批履历、配置变更记录、库存流水、登录审计** 等任意时序信息。节点建议结构：**标题** + **操作者/系统** + **可选备注** + **时间戳**（+ 来源 IP 等，等宽小字）。已完成节点可用对勾或实点；**进行中**可用 orange 系强调标题；未发生步骤用 gray 弱化。

### 日程 / 列表行左侧色条（分类条）

参考图中列表行左侧 **3～4px 竖条** 表示类别（会议 / 客户等）。在 OMS 中：

- **宽度 3px**，**radius-1**，高度约为行高 **− 2×space-2**  
- **颜色** 必须从 **Purple / Blue / Green / Orange** 的 **solid 9 或 11** 中选，且**同一屏同类 ≤4 种**，避免彩虹条  
- **不得**单独用色条传达关键状态；**最终结果**仍以 **点 + 文案** 为准（见 [16](#16-设计原则)）

### Recent Activity 动态流

仪表板或首页右侧 **「最近动态」** 与上节时间线共享信息层级规范：**每行** 可选 **32px 圆形头像**（radius-6）+ 主文案（size-4）+ 时间（size-2、mono 可选）；**行距** **space-4**；容器 **radius-4**、白底、**shadow-2**。

## 15 警告与风险卡片

### Warning & Risk Card

使用 **amber-2** 背景 + **amber-6** 边框。在全站范围内，琥珀可用于 **「需注意但非错误」** 的摘要：风控提示、库存临期、合同即将到期、第三方接口降级等 — **与促销 banner 区分**（促销多用 `b-brand` / 实心 CTA，见 [10](#10-按钮)）。

示例信息：标题、数据来源与时间、若干指标行与轻量进度条；避免与同屏 **btn-brand** 抢视觉主声量。

## 16 设计原则

### Design Principles

1. **Neutral first, accent second**  
   Gray-12 (#1F1D1C) 为主色。品牌琥珀 (#FFA902) 是稀缺信号 — 稀缺才有力量。若处处高亮，则没有重点。

2. **12-step semantic precision**  
   不按感觉选色。每次用色应能引用 step（例如「amber-11 用于低优先级徽章文字」）。若某 step 未定义用途，则该用例不成立。

3. **Step-6 borders, no heavy shadows**  
   卡片与页面以 1px gray-6 分隔，阴影最多 shadow-2。厚重投影往往意味着设计债 — 优先用边框 + 背景分层。

4. **Type does the hierarchy work**  
   层级靠字号与字重对比，而非用颜色弥补弱排版。例如 size-8/700 的 KPI 数值配 size-3/400 标签已足够表达主次。

5. **Status is always a dot + text**  
   不以单色传达状态 — **6px 色点 + 文字标签**。色觉障碍用户应能通过**文字**区分「进行中 / 成功 / 失败 / 各队列名」等，而非仅靠点颜色。

6. **One primary button per hierarchy level**  
   页面级动作用 btn-p；区块级（如保存草稿）用 btn-s。同一范围内两个 btn-p 通常说明层级决策未做清。

7. **Soft density on dashboard, dense on data**  
   仪表板、工作台允许更大 **区块间距（space-6～space-9）** 与 **更轻阴影**；**高密度列表、财务表格、日志表** 保持紧凑，**不**把首页的大留白硬套到表格行高上，避免一屏信息量骤降。

### Anti-Patterns

| 不要做 | 应改为 |
|--------|--------|
| 用 `#FFA902` 做主操作按钮色 | `btn-p` 使用 gray-12 (#1F1D1C)；品牌仅用于促销 |
| 品牌琥珀占单屏可视面积 > 10% | 限制在徽章填充、价格数字、每屏最多 1 个促销 CTA |
| 硬编码不在 12 级色阶内的 hex | 使用 step token，如 `var(--amber-9)`，避免随意内联 `#FFA902` |
| 用 `red-9` 做「紧急」优先级徽章（与拒绝同色） | 紧急用 `b-urgent`（red-2 底 + red-11 字）；拒绝状态用红点等区分 |
| 仅用 placeholder 当标签 | 始终在输入上方保留持久 `field-label` |
| 所有卡片统一用大圆角「像参考图」 | **数据区卡片默认 radius-4**；仅 **仪表板全宽重点卡、欢迎容器** 使用 **radius-5**；模态仍用 radius-5 |
| 页面级卡片使用 shadow-5 / -6 | 卡片用 shadow-2；shadow-4+ 预留给 Popover 与浮动面板 |
| 同页混用 Inter 与 Roboto | 全 UI 用 Inter；仅 ID、时间戳、代码用 JetBrains Mono |

### CSS Variables Quick Reference

| Variable | Value | Role |
|----------|-------|------|
| `--gray-12` | #1F1D1C | 主操作、标题、关键文字 |
| `--amber-9` | #FFA902 | 品牌实心 — 促销 |
| `--amber-2` | #fff8d6 | 品牌背景淡色 |
| `--amber-11` | #8c5c00 | 品牌文字 — 浅底上 |
| `--green-9` | #29a383 | 成功 / 完成类实心操作与状态 |
| `--red-9` | #e5484d | 错误 / 危险 / 失败类实心 |
| `--blue-11` | #0060cf | 链接、ghost 按钮文字 |
| `--orange-9` | #f76b15 | 首要待办 / 警示类状态点 |
| `--border` | gray-6 #dddbd8 | 默认描边 |

## 17 软质界面与仪表板排版

本节提炼 **Soft UI / 现代企业仪表板**（如 Zaga 类参考）中与 NearGo OMS **可兼容**的共性，并**绑定到既有 token**，避免「照抄视觉、脱离变量表」。

### 17.1 整体气质（What we adopt）

| 维度 | 参考图特征 | NearGo OMS 落地 |
|------|----------------|-----------------|
| 气质 | 轻、透气、白 + 浅灰底 | **surface 白 + gray-1 页底**；不用纯灰大色块铺底 |
| 分隔 | 细线 + 极轻阴影 | **gray-6 描边为主**，shadow-2 封顶于内容卡 |
| 强调 | 黑字主标题 + 灰字辅文 | **gray-12 / gray-11 / gray-9** 三级即够；琥珀仍守稀缺原则 |
| 彩色 | 粉紫蓝黄等柔和点缀 | **仅**小图标底、列表左侧 3px 条、状态点；色值出自 [01](#01-色彩) 语义阶 |
| 组件 | 圆角偏大、按钮偏药丸 | **仪表板主角卡 radius-5**；药丸形 **radius-6** 限 **侧栏入口 / 筛选 chip**，表格主按钮仍 radius-3 |

### 17.2 排版骨架（一页式总览）

```
[ Breadcrumb ]
[ Greeting 28px / 700 ]  +  [ subtitle 14px / 400 gray-11 ]
        ↓ space-6 ~ 7
[ KPI strip — 横向 3～5 项，space-5/6 分隔 ]
        ↓ space-6 ~ 7
[ Full-width priority card — radius-5, pad space-5/6 ]
        ↓ space-7
[ Row of 2–4 equal cards — gap space-5, radius-4 ]
        ↓ space-7 ~ 8
[ Two columns: main list 1.5~2fr | activity 1fr, min 280px ]
```

### 17.3 与「列表 / 表单 / 详情」页的边界

| 页面类型 | 圆角与阴影 | 垂直间距 |
|----------|------------|----------|
| 仪表板、运营总览、工作台 | 允许 **radius-5** 主角卡；KPI **radius-4** | **space-6～space-9** 区块间距 |
| 各类数据列表、宽表、日志 | **radius-4** 容器；行 hover **shadow-1** | **space-4～space-5**；不强行放大问候区 |
| 表单、详情、设置 | 与全局 token 一致 | 分区 **space-5** |

### 17.4 图标与插图

- **线型图标**：描边 **1.25～1.5px**，尺寸 **18～20px**，默认色 **gray-11**，hover **gray-12**  
- **勿**在侧栏与 KPI 混用填充卡通与线性两套；OMS 以 **线性 + 语义色小底** 为主

### 17.5 验收清单（设计走查）

- [ ] 首页是否有 **≤1 处** 28px 级问候标题，且下方 KPI 未挤在 16px 内  
- [ ] 是否仅 **一张**「全宽重点卡」使用 **radius-5**，其余卡为 **radius-4**  
- [ ] 双栏底区右列是否 **≥280px**，且主列未低于 **56%** 宽  
- [ ] 列表左侧色条是否 **≤4 色** 且均来自语义 scale  
- [ ] 侧栏若含搜索 + 主入口按钮，是否未与内容区 **第二个 btn-p** 冲突
